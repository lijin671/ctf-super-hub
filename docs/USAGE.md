# 使用说明

## 推荐入口

优先使用 `ctf-super-hub`。

### 默认推荐
- 有题面/附件/服务：`auto + teaching`
- 很迷茫：`brainstorm + teaching`
- 用户明确指定类别：`manual + teaching`

## 三种输出风格

### teaching
适合新手。

### competition
适合比赛时快速推进。

### hints-only
适合只想拿提示、不想被直接剧透。

## 常见使用场景

### 我有 ELF 文件
优先让 `ctf-super-hub` 自动判断，通常会落到 `ctf-reverse` 或 `ctf-pwn`。

### 我有网站 URL
通常先落到 `ctf-web`。

### 我只有一句模糊题面
先走 `brainstorm`。
